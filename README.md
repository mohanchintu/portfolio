## 🌟 Dual-Mode Interactive Experience

This portfolio features **two distinct viewing modes** accessible via the top navigation bar:

1. **Figma Slide Deck Mode (18 Pages)**:
   - Faithful recreation of all 18 slides from the Figma Community design template.
   - Includes keyboard arrow key navigation (`←` `→` / `Space`), fullscreen toggle, and an interactive 18-slide thumbnail carousel bar for instant section jumping.
   - High-fidelity 3D iPhone 16 Pro device frames showcasing realistic app flows.

2. **Continuous Responsive Web Scroll Mode**:
   - Modern single-page web portfolio with sticky header, live metric counters, filterable skill matrices, and responsive drawer navigation for mobile devices.

## 🏃 Quick Start

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/mohanchintu/Portfolio-2.git
cd Portfolio-2

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
